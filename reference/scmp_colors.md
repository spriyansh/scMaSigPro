# Colours of the paths

`scmp_colors()` returns `n` contrasting colours: those of a fixed
palette of nine, then named colours of
[`grDevices::colors()`](https://rdrr.io/r/grDevices/colors.html).

## Usage

``` r
scmp_colors(n)
```

## Arguments

- n:

  The number of colours.

## Value

A character vector of `n` colours.
